# Panta Copilot — 2-Minute Tester Task

Want to help harden an open pipeline? This takes about two minutes, needs no account,
and every result gets logged below with a date.

## The task

1. Open **https://loveoftheai.github.io/panta-copilot/** (Quotes tab).
2. Pick any market → any side → any amount.
3. Open the same market on the official **https://panta.market**.
4. Compare what you see (price / availability / rejection reason if any).
5. Report back: reply to the X post, or open a GitHub issue, with either
   **"一致" / "matches"** or a screenshot of the difference (include market + time).

That's it. Divergences you find go straight into the fix queue.

## Ground rules

- Compare what the screens actually show, not what they should show.
- If both sides error, that's still a valid data point — say so.
- No login, no wallet, no payment involved at any step.
