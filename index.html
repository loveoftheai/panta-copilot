How this works

Panta Copilot is a prediction-market desk built on the Panta API — binary YES/NO markets on Solana, quoted in USDC, where the API never custodies wallets: it returns unsigned transactions, your wallet signs.

The agent pipeline (the “AI” part, honestly disclosed)

  • An autonomous coding agent (Claude Code on a DGX Spark) calls the Panta API on a schedule: full catalog pagination → per-market details → tradability probes (real primaryorderquote calls).
  • It computes the stats you see in the Daily Brief, writes the snapshot data/snapshot.json, and ships it to this page.
  • The chat layer is a transparent rule-based NLU (intent classification + fuzzy market matching) over that snapshot — no hidden LLM calls, no hallucinated prices. Every number on this page traces to a Panta API response.

Trading flow (as the API designs it)

  1. POST /primaryorderquote/ — simulate a YES/NO fill on the bonding curve (shares, avg price, fee).
  2. POST /primaryorderbuild/ — get an unsigned Solana transaction from a live quote.
  3. Your wallet signs. You broadcast on your RPC.
  4. POST /primaryordersubmit/ — report the signature; Panta confirms asynchronously.

This demo shows steps 1–2 against real markets; signing is left to a real wallet (the app never holds keys).
