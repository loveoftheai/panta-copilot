Persistent registry — every market ever seen

Panta's live list rotates and caps at 50 per pull; this registry is the union of every market the agent has ever seen across pulls. A sweep runs every 2 hours: one catalog pull for discovery, then per-market detail pulls — the list endpoint carries no prices, details are the price source. A point is appended only when price / phase / volume changed; flat sparkline sections mean no change was recorded. Markets without a sparkline haven't been enriched with a detail pull yet.

Recorded observations at sweep cadence — not live prices. Titles come from the daily detailed pull; markets not yet detailed show category · id.

Recorded quotes (not live)

The pipeline records a real POST /primaryorderquote/ for each market × side × amount at snapshot time (daily). Pick a combination to see the recorded result — fills and rejections alike. Quotes are not refreshed on demand here; nothing is signed or broadcast by this app.

How this works

Panta Copilot is a prediction-market desk built on the Panta API — binary YES/NO markets on Solana, quoted in USDC, where the API never custodies wallets: it returns unsigned transactions, your wallet signs.

The agent pipeline (the “AI” part, honestly disclosed)

  • An autonomous coding agent (Claude Code on a DGX Spark) calls the Panta API on a schedule: the market catalog (one capped pull — the server's cursor endpoint never advances) → per-market details → tradability probes and a recorded quote matrix (real primaryorderquote calls).
  • It computes the stats you see in the Daily Brief, writes the snapshot data/snapshot.json, and ships it to this page.
  • The chat layer is a transparent rule-based NLU (intent classification + fuzzy market matching) over that snapshot — no hidden LLM calls, no invented prices — market numbers are derived from Panta API responses recorded in the snapshot (computed stats and formatting aside).

Trading flow (as the API designs it)

  1. POST /primaryorderquote/ — simulate a YES/NO fill on the bonding curve (shares, avg price, fee).
  2. POST /primaryorderbuild/ — get an unsigned Solana transaction from a live quote.
  3. Your wallet signs. You broadcast on your RPC.
  4. POST /primaryordersubmit/ — report the signature; Panta confirms asynchronously.

This demo shows step 1 (recorded quotes) against real markets; steps 2–4 — order building, signing, broadcasting — are not implemented here: they belong to your wallet and tooling. The app never holds keys.
